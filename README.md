Lumos – End-to-End User Journey

1. Landing Screen – Start a New Session

This is the main UI screen of Lumos.

The journey begins when the user clicks on the “New Session” button.

Clicking this opens the New Session Setup Screen.

⸻

2. Document Upload & Basic Details

On this screen, the user can:
	•	Upload a document
	•	Modify the file name
	•	Select the date
	•	Enter the company name

Once all details are filled in, the user clicks Confirm.

After confirmation, the file appears in the “Add Documents” section.

⸻

3. Adding Additional Knowledge

To enhance the output quality, users can add contextual knowledge such as:
	•	Company knowledge
	•	Industry knowledge
	•	Personal knowledge

This additional knowledge can be selected directly from this section and attached to the session.

⸻

4. Industry Selection & Generate

Once all required inputs are provided:
	•	The user selects the Industry
	•	Then clicks on the Generate button

When Generate is clicked:
	•	Document Indexing begins
	•	The request enters the Processing Queue

⸻

5. Status Tracking & Transparency

Users can monitor progress in the Status Panel, which displays:
	•	Whether the file is marked as the Main File
	•	File Indexing Status
	•	Answer Generation Status
	•	Execution Time

This ensures full visibility into system processing.

⸻

6. Predefined Answers – Current Section

Once answer generation is complete, the output appears in the Current Section.

Here, users can navigate through six predefined questions.

⸻

7. Summary Section

The first predefined output is the Summary.

In this section:
	•	Users can view the generated summary
	•	Citations are displayed
	•	Source references are available for validation and transparency

⸻

8. Follow-up Questions

Users can ask follow-up questions related to the generated output.

The system dynamically processes the query and indicates the routing method being used, such as:
	•	QA-based routing
	•	RAG-based routing

This adds technical transparency to the workflow.

⸻

9. Manage Context

Users can further enhance accuracy by clicking on Manage Context.

From here, they can:
	•	Upload additional files
	•	Add more knowledge sources
	•	Select relevant contextual inputs
	•	Click Submit

Once submitted, the additional context becomes part of the active session.

All subsequent follow-up questions will use this updated context for improved results.
